# Mohamed Khaled | Cyber-Noir Portfolio

A high-performance personal portfolio built with a premium Cyber-Noir aesthetic. This project serves as a showcase of high-end visual excellence, sophisticated user interactions, and modern frontend architecture.

---

## ✨ Key Features

### 🌌 Immersive Visuals
Experience an interactive digital environment featuring a custom fluid simulation. The background reacts and swirls in response to your cursor movements, creating a unique, living experience for every visitor.

### ⚡ Dynamic Interactivity
The interface feels alive through advanced based interaction and a proprietary "Reveal" engine. Elements respond to your presence, illuminating and providing tactile feedback as you navigate the site.

### 🌓 Seamless Theme Switching
Switch between a deep, immersive Dark mode and a clean, high-contrast Light mode instantly. Utilizing native browser APIs, the transition is professional and fluid with zero layout shift.

### 🔄 Real-time Synchronization
Built for the modern web, the portfolio utilizes live data synchronization to ensure content and project details are always accurately presented through a real-time data layer.

### 🏎️ Performance Optimized
Engineered from the ground up for speed. The entire experience is locked at a stable 60fps, utilizing GPU-accelerated animations and efficient state management to ensure a butter-smooth experience on all devices.

---

## 🛠️ Tech Stack

- **Core Framework:** React 19 & TypeScript
- **Global State:** Zustand
- **Styling:** Tailwind CSS (v4)
- **Animation Engine:** Framer Motion
